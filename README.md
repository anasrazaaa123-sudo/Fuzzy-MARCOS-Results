This repository contains the complete set of results obtained from the application of the Fuzzy MARCOS method for the evaluation and ranking of prostate cancer drug candidates.

The dataset includes all essential computational steps, such as:
- Construction of the decision matrix
- Normalization process
- Application of fuzzy weights
- Utility function evaluation
- Final ranking of alternatives

These results are provided in a structured format to ensure transparency and reproducibility of the research work. The repository can be used for validation purposes, comparative studies, and further advancements in multi-criteria decision-making (MCDM) techniques, particularly in healthcare and pharmaceutical analysis.
